Product

Movies catalog

Open the Movies section, scan posters, search within the catalog and jump into full detail pages.

Series catalog

Browse shows, track seasons, continue the next episode and inspect available episode releases.

Release ranking

Continue Watching

Progress shelves use posters or episode imagery so unfinished movies and series are recognizable.

Library actions

Add to library, mark watched, favorite, rate, share and manage local history from detail pages.

Cast navigation

Actor rows and detail tabs keep discovery connected instead of trapping users on one title.

Playback bridge

Streamly starts the selected release through the local playback path and keeps progress local.

Local-first settings

System Requirements

Built for modern Apple Silicon Macs.

  • macOS 13.0 or newer.
  • Apple Silicon M1 or newer.
  • Internet connection for metadata, source lookup and release updates.
  • Free disk space for cache, subtitles, diagnostics and temporary playback data.

Installation

Download the DMG, then move the app to Applications.

  1. DownloadGet the `.dmg` from the latest GitHub Release.
  2. DragDrag Streamly.app to Applications.
  3. OpenLaunch the app from Applications.
  4. AllowIf macOS blocks an unsigned build, open it from Privacy & Security with Open Anyway.

Privacy

Local-first by default.

  • Local library and history stay on this Mac.
  • No telemetry is enabled by default.
  • Credentials are stored in Keychain.
  • Diagnostics export happens only by user action.

Legal Note

Streamly is a media client.

  • Streamly does not host or provide media content.
  • Users are responsible for content sources and rights.
  • The app does not bypass DRM, paywalls or captcha.
  • Movie and TV metadata is provided by TMDB.
