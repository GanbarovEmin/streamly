Features

Everything needed for a first native macOS release.

Native macOS app

SwiftUI interface designed for desktop-first browsing and playback.

Apple Silicon optimized

Targeted at M1 or newer Macs with macOS 13.0+.

Netflix-like dark interface

Graphite surfaces, cinematic shelves, soft glow and quiet controls.

Torrent streaming architecture

Designed to stream without manual full-file downloads.

Embedded mpv playback

Playback layer prepared around an embedded libmpv engine.

TMDB metadata

Movies and series get metadata, posters, ratings and context.

Continue Watching

Resume later from local watch history and progress.

Local Library

Keep saved movies, series, favorites, ratings and lists on this Mac.

User Lists

Create watchlists and personal collections without cloud sync.

Subtitles

Embedded, local and OpenSubtitles-ready subtitle workflows.

Local-first privacy

No telemetry by default; credentials are stored in Keychain.

Auto-updates

Sparkle 2 appcast updates connected to GitHub Releases.

How It Works

Four steps from discovery to playback.

01

Search

Find a movie or series with metadata and release context.

02

Choose best release

Compare quality, seeders, size and source before playback.

03

Stream

Start watching through the embedded playback architecture.

04

Continue later

Return from Continue Watching, Library or personal lists.

System Requirements

Built for modern Apple Silicon Macs.

  • macOS 13.0 or newer.
  • Apple Silicon M1 or newer.
  • Internet connection for metadata, search, subtitles and updates.
  • Enough free disk space for temporary cache.

Installation

Download the DMG, then move the app to Applications.

  1. DownloadGet the `.dmg` from the latest GitHub Release.
  2. DragDrag CineFlow.app to Applications until the bundle is renamed in a future task.
  3. OpenLaunch the app from Applications.
  4. AllowIf macOS blocks an unsigned build, open it from Privacy & Security with Open Anyway.

Privacy

Local-first by default.

  • Local library and history stay on this Mac.
  • No telemetry is enabled by default.
  • Credentials are stored in Keychain.
  • Diagnostics export happens only by user action.

Legal Note

Streamly is a media client.

  • Streamly does not host or provide media content.
  • Users are responsible for content sources and rights.
  • The app does not bypass DRM, paywalls or captcha.
