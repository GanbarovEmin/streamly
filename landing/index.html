From discovery to playback in four clear steps.

01

Browse

03

04

What Is Inside

Requirements

Built for modern Apple Silicon Macs.

  • macOS 13.0 or newer.
  • Apple Silicon M1, M2, M3, M4 or newer.
  • Internet connection for metadata, source lookup and release updates.
  • Free disk space for cache, subtitles, diagnostics and temporary playback data.

Installation

Install like a normal Mac app.

  1. DownloadGet the latest `.dmg` from GitHub Releases.
  2. DragMove Streamly.app into Applications.
  3. OpenLaunch Streamly from Applications.
  4. AllowIf macOS blocks the unsigned beta, use Privacy & Security -> Open Anyway.

Privacy

Local-first by default.

  • No telemetry is enabled by default.
  • Library, history, settings and cache stay on this Mac.
  • Credentials use macOS Keychain where supported.
  • Diagnostics export is local and user-triggered.

Legal

Streamly is a media client.

  • Streamly does not host or provide media content.
  • Users choose and configure their own sources.
  • The app does not bypass DRM, paywalls or captchas.
  • Users are responsible for content rights and local law.
